# Marketing

Written by `/market` (`.claude/skills/market/SKILL.md`) and reviewed by `agent:marketing-claims-reviewer`. Everything here is a plan or a draft: a founder publishes it. Claude never posts, emails or messages anyone outside the repo.

| File | What |
|---|---|
| `positioning.md` | Who it is for, the problem, the promise, proof points, how we differ, words to use and avoid, the one-line description |
| `launch-plan.md` | Four weeks around launch day, each step with an owner and a done-when line |
| `content-calendar.md` | 12 weeks of guides and how-tos from real search questions; built with `/update` |
| `listing-refresh.md` | Proposed Play listing changes with the reason for each |
| `social/<YYYY-MM>.md` | Post drafts per channel, with the image to make, UTM link and the channel's self-promotion rule |
| `email/<name>.md` | Copy for opt-in emails only (welcome, receipt follow-up, renewal reminder) |
| `reports/<YYYY-MM>.md` | Monthly numbers from free analytics, what worked, next three actions |
| `consents.md` | Written permission for any real testimonial (name and date only) |

Rules: only claim what is built and tested; no invented numbers, reviews or testimonials; UTM links to the product's own domain; free tools only, paid ones are NEEDS HUMAN with the cost.
