# Specialist reviews

One file per review, written by `/review` and by `/newapp` phase 10: `<YYYY-MM-DD>-<branch>.md` (slashes in the branch name become `-`).

Each file lists the reviewers that ran, their final verdict, the merged findings table (S1 → S4) with what was fixed in which commit, what is still open with its BUG or RSK id, and what could not be checked. Format and rules: [`docs/standards/agent-reviews.md`](../standards/agent-reviews.md).

Read the latest file for a branch before reviewing it again, so repeated findings are spotted.
