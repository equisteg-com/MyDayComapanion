# Phase 1 — Competitor & gap analysis

1. Web-search the keywords from the brief. Identify the top 5–8 competitors (Google Play apps + websites).
2. For each: name, URL, rating, approx installs, core features, monetization, UX strengths, top complaints in 1–3★ reviews (paraphrase, don't copy).
3. Build a feature matrix (features × competitors, plus column "Us").
4. Gap list: problems users complain about that nobody solves well.
5. Final scope:
   - MVP must-haves = prototype REQs + parity features users expect.
   - 3–5 differentiators chosen from the gaps. Each must be feasible in this stack and justified by real complaints.
   - Explicit non-goals.
6. Save `docs/competitor-analysis.md`; append new REQs to the brief (source: "competitor gap").
7. If mode is `review`: show scope and wait.
